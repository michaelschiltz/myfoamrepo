# Croatian archives online — ARHiNET and the access layer

<http://arhinet.arhiv.hr/> — the national archival information system, run by the Hrvatski državni arhiv

## The structure

**One national descriptive system over a network of state archives** — Zagreb, Dubrovnik, Zadar, Split and the regional repositories — with a *digitalni arhiv* section alongside the descriptive registry.

That is closer to the French model than to the German: **a single frame, many custodians**. For a small country it works, and it means a Croatian search does not need to know which tier an institution belonged to.

⚠️ Extent of digitisation, reuse terms and any API are unestablished and should not be assumed from the descriptive coverage. The descriptive layer is national; the image layer is almost certainly not.

## Why Croatia is the last European country in this survey and not the least

Because [[Drzavni arhiv u Dubrovniku]] is a first-rank repository for a family the census already codes, and the rest of Dalmatia is the corroborating set around it. **This is not a marginal national pass appended for completeness** — it is the archive behind `Ragusan collegantia is unilateral and Venetian collegantia is bilateral`, which is an argued claim in the vault resting on a repository nobody in this project has visited.
