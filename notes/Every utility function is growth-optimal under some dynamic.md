# Every utility function is growth-optimal under some dynamic

Peters and Adamou's Theorem 4.1 shows that any invertible utility function with a twice-differentiable inverse is the ergodicity transformation of some class of wealth dynamics (eq. 4.2). Bernoulli's logarithm is growth-optimal under geometric Brownian motion, linear utility under additive Brownian motion, Cramer's square root under a CIR-like process, a convex "risk-seeking" exponential under its own dynamic. **The theorem concedes the "EE is Bernoulli" objection and generalises it.** Every expected-utility agent can be rationalised after the fact as a growth optimiser facing the matching dynamic.

## What survives

The framework's distinct empirical content is then a single claim: that the dynamic can be observed independently of the behaviour it is used to explain, and that behaviour moves when the dynamic moves while preferences stay put. That is respectable and testable — it is the hypothesis the paper states in §7 and the one the Copenhagen and Brussels experiments test — but it is a theory of *which* utility function applies, not a refutation of utility theory. The §7 polemic against expected utility sits awkwardly beside a theorem that vindicates it as a representation, and calling the result an "axiomatisation" overstates a sufficient-condition correspondence with no preference primitive and no representation theorem.

## Consequence for the project

The vulnerability already filed at [[Jensen supplies the gap but only the dynamic privileges the logarithm]] — the arbitrariness has moved from the utility function to the dynamic — is now the programme's own published position, not a referee's objection. For historical cases the dynamic is inferred, often from the evidence it is then used to explain. Two defences remain, both in the project's design rather than in the theory: **record the regime before coding the institution** (Part 1, Objective 1; the WP4 regime markers), and **prefer predictions that no fixed utility can mimic** — those that run off absorption ([[The utility mapping fails exactly where absorption begins]]) or off mixed dynamics ([[The commenda splits a dynamic that has no utility representation]]).
