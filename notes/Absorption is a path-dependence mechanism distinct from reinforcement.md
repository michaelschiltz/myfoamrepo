# Absorption is a path-dependence mechanism distinct from reinforcement

The path-dependence literature runs almost entirely on reinforcement. Its canonical mechanism is increasing returns generating multiple attractors, and its canonical formal object is the generalized urn. Absorption is a *different* mechanism producing order-sensitivity, and it has not been developed as such.

The contrast is sharp on every axis. Reinforcement is **selective**: several outcomes are available and the path picks one, with no outcome intrinsically worse. Absorption is **eliminative**: one outcome is terminal and the path either avoids it or ends. Reinforcement requires positive feedback from the state to the transition probabilities; absorption requires no feedback at all, only a boundary. Reinforcement produces a distribution over limits; absorption produces a survivor set and a void.

This matters for the book because **entity-shielding is a barrier-relocation technology**. Shielding does not raise the expected return of a venture. It moves $b$ downward, which changes *which orderings are lethal* — the claim developed in [[Terminal wealth is permutation-invariant but survival is not]] and anchored on [[Absorbing barrier]]. So the institutional innovation at the centre of the project acts on the absorption mechanism, not the reinforcement one. Arthur's apparatus, borrowed wholesale, would describe the wrong thing.

The comparison has not been run in either literature. Path dependence has never taken absorption seriously as a mechanism; the ergodicity programme has never framed the barrier as a path-dependence result. Stating the two as parallel mechanisms — one selective, one eliminative — is the contribution, and it is what licenses using the vocabulary of path dependence without inheriting Arthur's assumptions about increasing returns, which the Japanese and comparative material does not obviously support.

**Referee objection to pre-empt.** Liebowitz & Margolis (1995) dismantle the QWERTY case empirically and reduce path dependence to three degrees, only the third being genuinely inefficient. The reply is that their critique lands on the reinforcement mechanism and passes over the absorption one entirely, because the barrier argument never claims inefficiency — only that survival is order-dependent. Making that reply explicit is cheap insurance.
