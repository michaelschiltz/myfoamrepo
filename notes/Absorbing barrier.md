# Absorbing barrier

A ruin state from which a multiplicative trajectory cannot recover — the governing fact behind time-average reasoning. Because the barrier is absorbing, a single crossing ends the trajectory, so the relevant object is not the ensemble average over survivors but the [[Time-average|time-average]] growth rate along the one path that must avoid it.

## Why the barrier is the formally strong case

An absorbing set is invariant by definition, so absorption is not an application of the ergodicity apparatus but an instance of its central condition: the state space is decomposed, and the invariant σ-algebra is non-trivial. This makes ruin the project's most defensible non-ergodicity claim, stronger than the variance-based one usually offered in the literature. The argument is set out in [[An absorbing barrier breaks ergodicity by construction]], with the qualification that most historical cases are better described as weak rather than strong breaking — see [[Distinguish strong from weak ergodicity breaking]].
