# MOC — Path dependence and sequence

Thematic hub for the algebra of order-sensitivity: when the sequence of events changes the outcome, and when the claim that it does is empty.

The cluster is built around one negative result and three mechanisms that escape it. Under bare multiplicative dynamics order does not matter; order matters when flows make the period map affine, when an absorbing barrier makes survival depend on the running minimum, or when reinforcement gives the process multiple attractors. A path-dependence claim that names none of the three is not doing work.
